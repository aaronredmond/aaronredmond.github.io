About

I'm a software engineer who enjoys building for the web. Outside of work I like turning small ideas into simple, focused tools, usually ones that run entirely in your browser with nothing to install and nothing uploaded.

I use Claude throughout my work: for writing code, exploring ideas and reviewing changes. This site and my tools are built with its help, and I'm happy to say so.

You'll find a few of them below: PhotoToPixel, which came from a love of retro games and pixel art, a text extractor, a wheel spinner, and some command-line scripts. More will show up here as I build them.

Tools

Small, simple things I've built that you can try right here in your browser, with nothing to install.

PhotoToPixel

Turn any photo into retro pixel art. Pick a console palette (NES, Game Boy, C64…), add dithering, ASCII mode or a CRT effect, and download a PNG.

React · Canvas · Vite · Built with Claude

Text Extractor

Pull text out of screenshots and images right in your browser using OCR. Paste or drop an image, then copy the result.

JavaScript · Tesseract.js · MIT · Built with Claude Source on GitHub

WheelGame

A random wheel spinner. Put your own options on the wheel or use a number range, weight the spokes, and spin to pick a winner.

JavaScript · Canvas · MIT · Built with Claude Source on GitHub

Scripts

Command-line tools you download and run yourself. Source is on GitHub.

Batch File Renamer

Cross-platform command-line tool for renaming files in bulk: add prefixes, suffixes, sequence numbers or dates, or search and replace with regex. A dry-run mode previews every change first.

Python · CLI · MIT

Playlist Creator

Builds random M3U playlists from audio files sorted into genre folders, and can copy them to a directory for easy transfer to another device.

Python · CLI · MIT
